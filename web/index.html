A terminal-native presentation engine.
Decks are ASCII-art animations that render in a terminal — or here.

[1]

present

Play a compiled deck. Arrow keys, loops, auto-play animations and fullscreen — the terminal player's behaviour, in the browser.

open → [2]

compile

Turn a source deck into a playable one. Runs the real engine — the same Rust bs compile uses, built to WebAssembly.

open → [3]

instructions

The authoring format in full, ready to copy into an LLM so it can write a deck for you. One button, one paste.

open →

the loop

  instructions  →  source.json  →  compile  →  playable.json  →  present
       copy for            an LLM         WebAssembly                        in this
       your LLM           writes it       (real engine)                      browser

Everything here runs locally in your browser — no deck is uploaded anywhere.

Prefer a terminal? bs compile source.json out.json && bs play out.json — github.com/bashslides/bs
